# 01-SOP-DOC: Document Control

> **Use this SOP to:** create, approve, issue, revise, withdraw, retain, and retrieve controlled GMP documents.

---

## 1. Purpose

This SOP establishes document control for GMP instructions, forms, templates, records, specifications, protocols, reports, drawings, logbooks, and quality system documents.

Controlled documentation ensures:

- current instructions are available where work is performed
- obsolete documents are removed from use
- changes are reviewed and approved
- records support data integrity and inspection readiness
- suppliers and outsourced activities use approved documents where required

## 2. Scope

Applies to paper, electronic, and hybrid GMP documents, including:

- SOPs, policies, forms, logbooks, templates, specifications, master batch records
- validation plans, protocols, reports, test scripts, risk assessments
- analytical methods, cleaning procedures, calibration/maintenance procedures
- drawings, recipes, labels, training materials, and quality agreements
- supplier-controlled documents used for GMP activities where adopted by the site

## 3. References

- FDA 21 CFR 211.22, 211.100, 211.180, 211.186, 211.188, 211.194.
- FDA 21 CFR Part 11 where electronic records/signatures apply.
- FDA Data Integrity and Compliance With Drug CGMP guidance.
- EU GMP Chapter 4, Documentation.
- EU GMP Annex 11, Computerised Systems.
- ICH Q10, Pharmaceutical Quality System.

## 4. Document Types

| Type | Purpose |
| --- | --- |
| Policy / Quality Manual | Defines high-level intent and PQS structure. |
| SOP / Work Instruction | Defines required steps and responsibilities. |
| Form / Template | Captures GMP execution data. |
| Specification / Method | Defines acceptance requirements or testing instructions. |
| Protocol / Report | Plans and records qualification, validation, investigation, or study work. |
| Logbook / Register | Chronological record of repeated GMP activities. |
| External document | Supplier, regulatory, pharmacopeial, standard, or manual used in GMP work. |

## 4.1 Document Control Scenario Rules

| Scenario | Required action |
| --- | --- |
| New or revised GMP instruction | Assign owner/ID/version, route SME and Quality review, approve before issue, assign training before use. |
| Obsolete document found at point of use | Remove it, assess whether it was used, open deviation if GMP work may be affected. |
| Supplier-controlled document used for GMP work | Register source/version, define owner, monitor updates, and assess changes before use. |
| Document error affects executed work | Open deviation, assess affected records/batches/systems, issue correction or revision. |
| Printed controlled copy is lost | Notify Document Control, assess impact, issue replacement only with reconciliation. |

## 5. Roles and Responsibilities

| Role | Responsibilities |
| --- | --- |
| Document Owner | Drafts content, maintains accuracy, reviews periodic currency, and initiates revisions. |
| Document Control | Assigns IDs, controls format/version, routes review, issues effective documents, archives obsolete documents, and manages retrieval. |
| Quality Unit | Approves GMP-impacting documents and changes. |
| SMEs | Review technical accuracy. |
| Training | Assigns training before effective use where required. |
| Users | Use current approved documents and report gaps or errors. |
| System Owner | Maintains electronic document system controls where used. |

## 6. Procedure

### 6.1 Create or revise

Document creation or revision must define:

- document title, ID, version, owner, effective date
- reason for creation/change
- affected departments, systems, products, or training
- related change control, CAPA, deviation, audit, or regulatory commitment
- review and approval route

GMP-impacting document changes must be reviewed by Quality.

### 6.2 Drafting rules

Documents must be:

- clear, concise, and practical
- written in active voice where possible
- consistent with approved terminology
- specific about roles, timing, records, and acceptance criteria
- free from uncontrolled placeholders
- aligned with current process and regulatory commitments

### 6.3 Review and approval

Reviewers confirm:

- technical accuracy
- GMP and regulatory alignment
- data integrity controls
- impacted records/forms/templates
- training impact
- effective date and implementation plan

Approvals must be complete before issue. Electronic approvals must meet applicable electronic record/signature controls.

### 6.4 Issuance and effective use

Document Control must:

- issue only approved versions
- make current documents available at point of use
- prevent use of obsolete versions
- control printed copies, if used
- ensure required training is complete before independent execution where required

### 6.5 Obsolete documents

Obsolete documents must be:

- removed from points of use
- marked obsolete or superseded
- archived according to retention rules
- retained when needed to reconstruct historical GMP activity

### 6.6 Periodic review

Documents must be reviewed at defined intervals based on risk and document type.

Review must confirm:

- content remains accurate
- roles and systems remain current
- references remain current
- linked forms and records remain aligned
- regulatory and process changes are reflected

If no change is needed, record the review outcome.

### 6.7 External documents

External documents used for GMP decisions must be controlled for:

- source and version
- owner
- applicability
- update monitoring
- point-of-use availability
- replacement or retirement

### 6.8 Document errors

If an active document contains an error:

1. Assess whether GMP work already performed is affected.
2. Open deviation if product quality, data integrity, validated state, or regulatory commitment may be affected.
3. Issue correction, temporary instruction, or revision through approved controls.
4. Train affected personnel as needed.

## 7. Records

Maintain:

- document master list
- review/approval history
- effective and obsolete versions
- distribution/issuance records
- training impact records
- periodic review records
- external document register
- document destruction records where applicable

## 8. Metrics

Track:

- overdue periodic reviews
- document changes by reason
- obsolete document use
- document-related deviations
- training completion before effective date
- uncontrolled copy findings

## 9. Quick Checklist

- Is the current approved version available at point of use?
- Are obsolete versions removed or clearly marked?
- Is training complete before use?
- Are forms/templates controlled?
- Can historical versions be retrieved?
- Are external standards monitored for updates?
