# GxP Standards Library

**A public-use standard for pharmaceutical validation.**

This repository contains the source content for [GxP Blueprint](https://gxpblueprint.com). It is published for internal use by organizations of every size under the [GxP Blueprint Community Licence 1.0](https://www.gxpblueprint.com/licensing), but it is not open for external contributions.

## Structure
* **00 Core Framework:** High-level policies and the "Why" behind validation.
* **01 Quality Systems:** foundational SOPs (GDP, Change Control).
* **02 Computerised Systems:** Modern, risk-based validation (CSA/CSV).
* **03 Equipment:** IOQ protocols and hardware testing.
